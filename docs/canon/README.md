# Canonical implementation specifications

This directory is **scaffolding**, not a substitute for the approved GDD and later explicit decisions.

Planned documents:
- `GAME_RULES.md`: consolidated combat, economy, story, modes and core invariants.
- `DATA_CONTRACTS.md`: versioned Resource, JSON and save schema contracts.
- `DECISION_LOG.md`: dated approved decisions with source, rationale and impact.
- `ART_UX_SPEC.md`: Android layout, visual style, assets, animation and interaction requirements.

Before editing gameplay, reconcile these files with the approved GDD, 127-page UI storyboard, and `docs/production/DECISIONS_TO_LOCK.md`. Mark unresolved rules clearly; do not silently promote provisional mockup values to canon.
