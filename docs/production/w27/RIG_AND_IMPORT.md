## Files, manifest and pivots

- Put approved master/source receipts under `assets/source-art/rangers/patrolman/` or the corresponding per-ID enemy directory `assets/source-art/enemies/e01/`. Put only validated transparent part PNGs under the matching `assets/imported/rangers/patrolman/` and `assets/imported/enemies/e01/`. Place individual tray/Intel thumbnails under the appropriate existing UI/portrait family. Keep review sheets in production docs and out of the player import list.
- Start from the W06 96 × 96 logical source, 384 × 384 raster canvas, 4 px per logical unit and foot anchor `[48,84]` (`[0.5,0.875]` normalized). Draw a right-facing three-quarter neutral. Crop each raster part with at least four transparent pixels on every side. Trim by real alpha around its authored shape. Use lossless RGBA PNG. Use separate `png`, `sha256`, `svg_layer_id`, stable `id`, `parent` and independent `draw_order` per part. Record file dimensions, art bounds, source/hash, status, rights and provenance. Keep `asset_version` and `schema_version` separate.
- Coordinates are top-left with +x right and +y down. `canvas_rect_px` is the part's `[x,y,w,h]` rectangle on the full canvas. Record `pivot_canvas_units`, `pivot_canvas_normalized` with components divided by 96, and `pivot_local_px = 4 × pivot_canvas_units − crop_top_left_px`. Root neutral joint is `pivot_canvas_units − ground_anchor_units`. Child neutral is `pivot_canvas_units − parent_pivot_canvas_units`. Declare art-relative grip, action/VFX and underfoot offsets independently from the placement cells.
- Record group ownership and attachment transforms for the shield, baton, hat, pouch and Scout prop. Smoke, damage accents, dust, underfoot HP, tile selection, sparse shadows and UI stay separable. Test maximum rotation of each authored shoulder, elbow, wrist, thigh, knee and boot join against both facing roots.

## Presentation-only Godot contract

1. Use `Facing/Skeleton` with `Bone2D → Sprite2D` for each approved part, independent `z_index`, `centered = false`, texture position `-pivot_local_px × 0.25` and local art scale `0.25`. Lossless textures, linear filtering and alpha border fix follow the Scout pilot. Check the upload size and do a named-phone review before changing texture density or packing the cutouts. The existing converter builds editable nodes from this metadata. Its root name and default state driver are Scout-specific. Generate new destination scenes with an explicit driver and unique visual identity after reviewing their node paths. [Converter](../../../tools/build_cutout_scene.py) · [Existing import example](../../../assets/imported/rangers/scout_sniper/head.png.import)
2. Bind by stable definition ID to a presentation root and index the live visual instance by the runtime actor/placement ID. Treat scene anchors as visual transforms of the existing board center, footprint center or route position. Use board-cell scaling relative to 80 units. Apply a visual foot offset in the presentation bridge so the sole and HP align naturally. Keep input, blockers and placement geometry in the existing board/placement state. For a two-cell Post visualize one wide object centered on the valid pair. All tile/HP/ghost effects are separate nodes or draws. [Board](../../../scripts/ui/sample_board.gd) · [Deployment state](../../../scripts/battle/deployment_state.gd)
3. Mirror only the right-authored visual `Facing` child at the feet. Recreate the basis as positive or negative x with y unchanged. HP, UI text, tile occupancy, route and attack hit logic stay on their existing owners. Use the placed facing for Patrolman. Scout may visually mirror when the presentation has a target side. E01's art follows existing route/actor direction. Preserve visual-only stacking when two E01 share a blocker.
4. Step animation time manually with the existing combat clock, matching C07's `advance_combat(seconds)`. Drive `play_state` from existing presentation events or read-only state changes, so speed, pause, dialogue skip and app resume keep their current timing. Effects and animation callbacks have no authority over damage, attack clocks, payout, waves, targets or saves. Keep actors' visual nodes/input masks noninteractive. A missing reviewed texture or pose routes to the existing labeled presentation fallback during development. [Clock](../../../scripts/battle/combat_clock.gd) · [C07 driver](../../../scripts/animation/scout_rig.gd) · [Campaign view](../../../scripts/battle/campaign_battle.gd)
5. Use original visual marks or real SVGs for scalable UI, with existing dynamic text and interaction states. Bind portraits by `portrait.manager` / `portrait.leader` plus exact authored pose. Use an independently editable master and transparent keyed expressions for each. Record source art bounds, alpha, pivot/baseline, and safe text/crop rectangle. Reference the UI pp. 20–21 composition at normal and 130% text. [Existing portrait control](../../../scripts/ui/story_portrait.gd)

## Verification for an approved delivery

Before import, reassemble all PNGs by crop top-left and draw order, compare against the source at 4× and at actual 80-unit tile scale. Verify contiguous chains and connected poses under both mirrors, lossless file dimensions, exact hashes, no bright fringe, no stray pixels and matching grip contacts. Record tests for rect offsets, bounds, nonempty alpha and pivots inside both parts. The two delivered kits include [Patrolman pose keys](../../../assets/source-art/rangers/patrolman/animation_contract.json) and [E01 pose keys](../../../assets/source-art/enemies/e01/animation_contract.json), exercised in an isolated Godot project. [Import acceptance](IMPORT_ACCEPTANCE.md)

Run pinned editor import and headless startup, then execute `scout_rig_test.gd`, `deployment_test.gd`, `enemy_combat_test.gd`, `logistics_test.gd`, `campaign_story_test.gd`, `campaign_navigation_test.gd` and `presentation_test.gd` from [tests/unit](../../../tests/unit/). Compare all per-stage gameplay outputs against the baseline after art binding. Run acceptance on an actual landscape phone at standard/enlarged text with art, 1×/2×, pause/Continue/Skip, valid and invalid drag, stacked block, damage, escape and retry. Verify D-014 provenance and the packaged paths with the C24 resource-selected export. [First Contact art batches](../W27_FIRST_CONTACT_ART.md#delivery-batches-and-acceptance)
