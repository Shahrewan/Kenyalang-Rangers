## How to apply a mission ticket

Use one stage JSON per mission ticket and commit only the approved fields. Dialogue and queue decisions can land independently when their triggers align. Edit the existing `dialogue_sequences`, `tutorial_hints`, `waves[].groups`, authored rest fields or `balance_trial` keys as approved. Recompute dependent intel totals and published QA cadence fields when a queue changes. Confirm unchanged IDs, map, order, starting prerequisites, authored count, debuffs and existing grant and supply contracts. Reserve payout edits for the Funds tickets and boss/shared actor changes for their own review. Use the current [loader](../../../scripts/data/campaign_content.gd) and [battle scene](../../../scripts/battle/campaign_battle.gd) as the normal entry points.

For every mission, run the existing Campaign resource and Story suites. Compare ordered spawn IDs, gate index and combat ticks, including the interval that crosses each ordered group boundary and zero rest on the last populated wave. Confirm each reviewed dialogue trigger selects the intended beat. At 1× and 2×, Continue and Skip leave the same resumed clock, active actors, HP, position, Integrity, Tokens, statuses, cooldowns, construction and queue. Check retry and replay through the real planner. Compare timer or trigger changes with [C14's executed checks](../../qa/C14_CAMPAIGN_MATRIX.md). Record player clears separately from the scripted damage route.

## Command baseline for implementers

Run from an isolated checkout with Godot `4.7.2.stable.official.ed1daf0bf` and a temporary profile. C24's suite and package procedures are in [tests/README](../../../tests/README.md), [C23 evidence](../../qa/C23_SYSTEM_AUDIT.md) and [C24 handoff](../../../export/C24_HANDOFF.md).

```sh
godot --headless --path . --editor --import --quit
godot --headless --path . --script res://tests/unit/campaign_resources_test.gd
godot --headless --path . --script res://tests/unit/campaign_story_test.gd
godot --headless --path . --script res://tests/unit/boss_combat_test.gd
godot --headless --path . --script res://tests/unit/c23_recovery_test.gd
godot --headless --path . --script res://tests/balance/economy_60_days.gd
```

Use an isolated normal Story build for the player cases. Verify pause, background/resume and touch at 1×/2× on a named landscape phone. Preserve the RC1 release identity and signing custody while following the C24 signed-update test. Record the exact resulting asset/data revision. Package only signed-off Campaign content and retain stage and save compatibility.
